# Hash Manifests

This folder contains SHA-256 hash manifests generated during evidence preservation and working-copy verification.

## Files

- `MASTER_SHA256.csv` — SHA-256 hashes for the preserved master VM evidence set.
- `WORKING_SHA256.csv` — SHA-256 hashes for the forensic working copy.

The manifests were compared before examination. No differences were identified between the master evidence set and the working copy.

These hashes document evidence integrity and support the chain-of-custody methodology used in this lab.
